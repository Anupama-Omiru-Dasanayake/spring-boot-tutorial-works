# Spring Boot Tutorial Works

A collection of practical exercises and implementations completed while learning **Object-Oriented Programming (OOP) with Spring Boot**.

This repository documents my progress in understanding Java OOP concepts and applying them to Spring Boot applications.

## Topics Covered

- Object-Oriented Programming in Java
- Classes, Objects, Constructors, and Methods
- Inheritance and Method Overriding
- Abstract Classes and Abstract Methods
- Polymorphism
- Encapsulation
- Spring Boot Fundamentals
- REST APIs and HTTP Requests
- JSON Serialization and Deserialization
- Data Transfer Objects (DTOs)
- Java Object-Oriented Design Principles

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Java JDK
- Maven
- Git

### Clone the Repository

```bash
git clone https://github.com/Anupama-Omiru-Dasanayake/spring-boot-tutorial-works.git
cd spring-boot-tutorial-works
```

### Run the Application

Using Maven:

```bash
./mvnw spring-boot:run
```

On Windows:

```bash
mvnw.cmd spring-boot:run
```

Alternatively, open the project in your IDE and run the Spring Boot application from its main class.
